This video documents my Vinternship journey, where I worked on building a full-stack application using the MERN stack (MongoDB, Express.js, React.js, and Node.js). In this vlog, I share my learning experience, challenges I faced, and how I implemented key features in the project.

Viewers will learn how I structured the backend using Node.js and Express, managed databases with MongoDB, and built an interactive frontend using React. I also briefly showcase parts of my code and explain how different components connect to create a complete working application.

This Vinternship helped me strengthen my problem-solving skills, improve my understanding of full-stack development, and gain real-world project experience. It enhanced my confidence in working with APIs, database integration, and building scalable web applications.
